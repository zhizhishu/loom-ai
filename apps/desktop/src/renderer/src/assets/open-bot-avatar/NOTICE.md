# open-bot-avatar shape library (MIT)

`*.json` in this directory and `LICENSE` are copied unmodified from
`open-bot-avatar` (MIT, https://github.com/DominikScholz/open-bot-avatar),
pinned at commit `684dddfe` — the same tree as npm `open-bot-avatar@0.2.0`,
which is installed as the runtime engine.

Only `gallery/*.json` shape definitions and `gallery/colors.json` (default
palette used for `defaultColor`) are vendored. No engine source is copied
here; the runtime is imported from the package.

Upstream copyright and the MIT permission notice are in `./LICENSE`. Any
modification of these files must keep that notice and stay MIT-compatible.
