# LOOM 工作空间交付 — 2026-11-14

## 现在能用什么

本轮沿用既定 Rust Core 架构与 Mikka / PiBot 风格的 loom-native 界面。主管亲自实现和审查 UI；后端、工作流与电脑授权按范围分派给本机 Pi 工兵，再由主管独立核验。任务、Run、成果版本、审查和用户接受仍以 Core 为唯一事实。

右侧工作空间统一为「工作 / 资产 / 流程 / 电脑」。切换页签或关闭重开时保留选中的工作；「创建工作」直接进入工作模式，「新对话」恢复正常的对话入口。全局搜索支持对话、助手、工作和成果，Ctrl/⌘K 可打开；点击结果定位真实 Core 记录。主管亲自检查日夜主题和窄屏截图；搜索面板在 390、760、1040、1605 宽度均无横向溢出。

创建助手采用统一流程，提供八个可编辑模板，运行端选择 Claude Code / Codex / DSH / Pi，能力分为 Skills / MCP / Rules / Hooks。入口可发现、导入、选择能力；保存配置与真实运行时装载分别表达，不把界面可选冒称四端全部实测。

本轮独立实例中的 Hanzi、Linxi、Beichen、Yezi 已通过正常 UI 配好 Pi / DeepSeek-V4.1-Flash，并刷新读回。单聊默认用助手名字；新对话显式选择被更快后台刷新覆盖的问题已经修复，并以真实延迟请求回归。

## 启动与使用

在此仓库双击 `Start-LOOM.cmd`。已有同一独立实例时打开页面；未运行时启动受管 Host，再打开浏览器。运行需要保留启动窗口。`Start-LOOM.cmd --check` 只检查状态，`--no-browser` 可不打开新页。

当前地址、进程和配置根从 `_artifacts/loom-ultimate-20261113/resume-01/preview/runtime.json` 读取。启动器绑定本轮已确认的独立 kit / data，不替换日常实例。源码入口是 `_artifacts/ship-20261114/start_loom.py`；它依赖现有本机 Python、受管资源和已配置的 Mindkit 凭据，不是可移植安装器或永久系统服务。

可直接与 Hanzi 单聊，也可创建群聊、指定主助手与工作位置，再查看右侧工作、成果和流程。电脑查看、人工接管、Agent 授权是分开的操作；启用服务不自动授予助手权限。

## 已完成的真实链路

在用户的实际 Chrome 中，经正常界面创建单聊、输入并发送一条带唯一校验码的消息。Core 记录的 Pi Run 成功，助手回复与该 Run 精确对应，真实模型为 `pi://model?provider=oct-chat&id=deepseek-v4.1-flash`。该消息要求不用工具，只证明真实模型回复。

首次证据：`_artifacts/ship-20261114/ui/browser-model-proof.json`、`ui/08-real-chrome-model.png`。最终重启后另有 `ui/final-browser-model-proof.json`，绑定最终二进制和前端资源；两次正常发送各自只有一次动作。验证读回没有业务写入，不意味着此前正常创建和发送没有写入。

对已完成链的只读复核 53 项断言通过，另有 15 项私有验收器离线边界检查。复核没有新增模型调用或业务写入。最终候选仍是 `pending`，自动派工策略已暂停，活动 Run 为零。技术验证和工兵主管批准不等于产品中的用户接受。

证据：`workflow-final-evidence.json`、`workflow-20261114T144432Z-47bd-revalidation-20261114T145732Z.json`，均位于本轮证据目录。五阶段模型工作流由 API 驱动；Chrome 直接发送另有独立证明，不混称整条五阶段均由浏览器点击完成。

### 电脑授权与撤权

修复 Host 对 Core 规范 digest 的解析、扁平 MCP 配置读取及脱敏定义校验：对已验证的同一 web owner、serverId 与 digest 使用现有 reveal 接口，只在内存中比较真实定义；冲突、缺失和异常形状继续拒绝，不降低脱敏或权限要求。

27 项 Rust 测试与 30 项专用测试脚本守卫通过。新的隔离环境完成 13 项真实 Windows 测试：截图；查看权限下拒绝点击与输入；明确控制授权后只对专用 Tk 窗口进行一次点击及固定文本输入；重复 request ID 拒绝；撤权成功；旧 token 与后续操作被拒绝。最终 Host、测试窗口、桥接子进程、监听、grants、MCP 注册和授权文件均已清理。

这证明真实 MCP 客户端 → Host/Core → Windows 的受限控制链。没有让真实模型发起电脑操作，Pi MCP 电脑入口继续关闭。最终实例提供授权服务，但启动不创建 grant，用户仍需显式授权。
