## 一句话

保留你已经喜欢的 LOOM 页面，让其中的 Bot 真正变成**一个不会因为关掉电脑或退出 Pi 就失忆、能管理多台电脑并交付结果的助手**。未来主要服务可以放在 Linux 云端，Windows、Mac 只需接入设备工具；需要时本地也可以运行 Pi/DSH/Codex 工兵。

## 你以后怎么用？

你打开 LOOM，直接对某个 Bot 或群聊说“去 Windows 电脑里看一下这个问题，修好后让 Mac 验证，再把结果给我”。Bot 自己判断怎么拆任务、需要哪个工兵、哪台电脑，做到哪里、被什么权限卡住，都会留在你现有的 **工作 / 资产 / 流程 / 电脑** 页面里。

你换电脑甚至用手机打开，仍是同一个 Bot；它的记忆、任务和成果跟着账号走，不被绑死在 Windows 的某个目录或一个 Pi Session。

## 电脑 B 为什么不用 DSH Host？

因为“谁动脑”和“谁动手”原本是两件事。

- **脑子**：在云端跑 Pi/DSH/Codex，让模型分析和分配工作。
- **手脚**：Windows B 安装一个轻量 `loom-device`，给云端 Bot 已授权的文件、终端、浏览器、屏幕等工具。
- **老板**：LOOM Core 记住任务、设备授权、证据和结果，决定什么时候问你确认。
- **按需本地工兵**：如果你的仓库很大、工具只装在 B 上，就把这件事交给 B 上的本地 Pi/Codex/DSH；无需排斥此模式。

你不应该面对“先选某个 CLI、选 Session、选 AgentHost”才能使用电脑 B 的复杂步骤。

## Mikka 和其他 GitHub 项目怎么学？

- Mikka：学长期 Bot、派活、需要你注意的事情、独立 Agent/Run、人工接管、工作结果回到 Bot。
- MindFS / AgentDock：学不靠每台机器安装模型 CLI 就可远程读文件、操作终端的工具接口。
- DeskFleet / UFO：学设备注册、实时状态、PTY/桌面、跨设备分工。
- Pi / DSH：比谁更适合当可更换的执行内核，不让其中一个绑架 LOOM 的产品。
- PiBot / ACCP / MOVO / AgenTeam：学能力分配、协作交接、审查、组织治理。

这叫**深入研究后融合成熟机制**；不是因为项目许可证就不看源码，也不等于直接把别人整个数据库塞进 LOOM。

## Pi 换成 DSH 吗？

**先不强换。** Pi 已有嵌入能力，DSH 适合复杂插件与环境隔离。两套都用同一个 DeepSeek V4.1 Flash/max、同样的任务与授权真实测试；谁表现更好，优先用谁，另一套保留为可选工具。远端电脑操作能力与选谁做脑子完全分开。

## 怎么判断真的完成？

最重要的不是“测试 100%”或“工兵说完成”，而是你看到同一个 Bot 对真实设备 B 做了一件安全操作，设备 B 上根本没有 Pi/DSH/Codex，结果进入 LOOM 的任务/资产页面，而且你可以随时撤销权限、接管屏幕或拒绝操作。完整清单在 [验收表](loom-mikka-first-acceptance-2026-11-15.md)。
